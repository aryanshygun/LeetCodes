# Privacy Policy

**LeetCode Automation**

This application is a personal automation tool used to publish software engineering content to the developer's LinkedIn profile.

The application may process:

* LeetCode solution source code
* Generated LinkedIn captions
* Generated images
* LinkedIn account authorization information required to publish posts

This information is used solely to generate and publish LinkedIn posts.

The application does not sell, rent, or share personal information with third parties for advertising purposes.

LinkedIn authentication information is used only to authenticate the account and publish posts through LinkedIn's API.

The application does not intentionally collect information from other LinkedIn users.

For questions regarding this privacy policy, please contact the application owner through the GitHub repository associated with this project.
